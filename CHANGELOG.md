## [0.1.0] - 2026-11-08

First public version.

### Added
- Sealed sandbox with a policy per seam.
- Declarative cases and expectations.
- Fakes with declared fidelity.
- Weighted defect signals, published with the score.
- Judged tier with a budget and a loud fail-open.
- Thresholds mapped to the process exit code.
- JSON and Markdown reports.
- Agent contract and replay runner, with the `replaygate` command.
- Demo booking agent with fixtures and cases, run in CI as its own gate job.
